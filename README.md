# Executive Copilot Immersion Materials

This repository contains lightweight materials for an executive-focused Microsoft 365 Copilot immersion experience for commercial banking leaders.

## Files

| File | Description |
| --- | --- |
| `index.html` | Simple landing page for GitHub Pages. |
| `VP_Commercial_Bank_Copilot_Lab.html` | Microsoft Learn-style HTML version of the participant lab. |
| `VP_Commercial_Bank_Copilot_Lab.md` | Participant-facing lab with three simple activities: prepare for an executive review, analyze a forecast workbook, and draft a leadership update. Includes instructions to download the sample Excel workbook and save it to OneDrive before using Copilot in Excel. |
| `Commercial_Bank_VP_Copilot_Prompts.md` | Copy-ready prompt library for commercial banking VPs. Prompts cover meeting prep, executive summaries, portfolio reviews, risk review, communications, and Excel analysis. |
| `Chief_of_Staff_Agent_Instructions.md` | Trainer-facing setup guide for creating a lightweight Chief of Staff agent in Microsoft 365 Copilot Agent Builder. Includes agent description, instructions, sample prompts, sharing guidance, and validation checklist. |

## Intended use

Use these files as supporting assets for a 90-minute executive Copilot immersion session. The materials are intentionally simple so trainers can adapt them to the audience while keeping the session focused on practical leadership workflows.

## Sample workbook

The Excel activity uses the sample workbook available at:

```text
aka.ms/sampleExcel2
```

Participants should download the workbook, save or upload it to OneDrive, and open the OneDrive copy before using Copilot in Excel.

## Trainer notes

- Keep demos within the features enabled in the customer environment.
- Use GPT model experiences only if those are the approved available models.
- Do not demonstrate unavailable features such as Notebooks, Pages, Teams Facilitator, or Copilot Skills in Excel or PowerPoint unless they are explicitly enabled.
- Remind participants to validate Copilot outputs before using them.
